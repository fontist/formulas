# Creative Commons Attribution 4.0

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-28a745)](https://spdx.org/licenses/CC-BY-4.0.html) [![Category: Open Source](https://img.shields.io/badge/Category-Open%20Source-28a745)]

**SPDX Identifier:** `CC-BY-4.0`
**SPDX Page:** https://spdx.org/licenses/CC-BY-4.0.html

## Quick Summary

The Creative Commons Attribution license allows free use, modification, and distribution with only one requirement: you must give appropriate credit to the original creator.

## Attribution Requirements

When using CC-BY fonts, you must:

1. **Identify the creator** - Name the font designer/foundry
2. **Provide a link** - To the original work or license
3. **Indicate changes** - If you modified the font
4. **License notice** - Include the CC-BY license reference

### Example Attribution

```
Font Name by [Creator Name] is licensed under CC BY 4.0
https://creativecommons.org/licenses/by/4.0/
```
