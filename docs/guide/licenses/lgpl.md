# GNU Lesser General Public License (LGPL)

[![License: LGPL](https://img.shields.io/badge/License-LGPL-28a745)](https://spdx.org/licenses/LGPL-3.0.html) [![Category: Open Source](https://img.shields.io/badge/Category-Open%20Source-28a745)]

**SPDX Identifier:** `LGPL-2.1` or `LGPL-3.0`
**SPDX Page:** https://spdx.org/licenses/LGPL-3.0.html

## Quick Summary

The GNU Lesser GPL is a weak copyleft license that allows linking with non-free software. For fonts, it typically permits free use while requiring modified versions to remain under LGPL.

## Permissions Overview

### ✅ Allows For

| Context | Permission | Notes |
|---------|------------|-------|
| Academic | ✅ Full | |
| Non-commercial | ✅ Full | |
| Commercial (Static) | ✅ Full | Documents can be proprietary |
| Commercial (Server) | ✅ Full | |
| Web (Hosting) | ✅ Full | |
| Desktop | ✅ Full | |
| Server/CI | ✅ Full | |
| Redistribution | ✅ Full | Must include license |
| Linking | ✅ Full | Can link with proprietary software |

### ⚠️ Conditional

| Permission | Condition |
|------------|-----------|
| Modification | Modified font must remain LGPL |
| Redistribution | Must provide source or offer to provide |
| Commercial use | Documents using font can be proprietary |

### ❌ Disallows For

| Permission | Notes |
|------------|-------|
| Proprietary derivatives | Modified font must stay LGPL |

## Key Difference from GPL

LGPL allows:
- Linking with proprietary software
- Using font in commercial documents without infecting them
- More flexibility than GPL for commercial use
