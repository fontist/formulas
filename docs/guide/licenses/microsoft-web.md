# Microsoft Web Fonts EULA

[![License: Freely Distributable](https://img.shields.io/badge/License-Freely%20Distributable-007bff)](#) [![Category: Freely Distributable](https://img.shields.io/badge/Category-Freely%20Distributable-007bff)]

**SPDX Identifier:** Not on SPDX

## Quick Summary

The Microsoft Web Fonts EULA allows unlimited redistribution of certain Microsoft fonts (like Arial, Times New Roman, Verdana) at no cost, provided you include the EULA and do not sell the fonts for profit.

## Permissions Overview

### ✅ Allows For

| Context | Permission | Notes |
|---------|------------|-------|
| Academic | ✅ Full | |
| Non-commercial | ✅ Full | |
| Commercial (Static) | ✅ Full | Documents, images |
| Commercial (Server) | ✅ Full | |
| Desktop | ✅ Full | |
| Server/CI | ✅ Full | |
| Redistribution | ✅ Full | Not for profit, with EULA |
| Bundling | ✅ Full | With software, include EULA |

### ⚠️ Conditional

| Permission | Condition |
|------------|-----------|
| Redistribution | Must include full EULA text |
| Distribution | Cannot charge for fonts alone |
| Copies | Unlimited copies allowed |

### ❌ Disallows For

| Permission | Notes |
|------------|-------|
| Profit from distribution | Cannot sell fonts standalone |
| Modification | Cannot edit font files (subsetting allowed for embedding) |
| Web embedding | Limited - check specific font EULA |

## Key EULA Excerpts

> "You may reproduce and distribute an unlimited number of copies of the SOFTWARE PRODUCT, provided that each copy shall be a true and complete copy, including all copyright and trademark notices, and shall be accompanied by a copy of this EULA."

> "Copies of the SOFTWARE PRODUCT may not be distributed for profit either on a standalone basis or included as part of your own product."
