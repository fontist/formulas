## Quick Summary

Fonts bundled with Adobe products (Creative Cloud, etc.) are licensed for use with those products. Additional licensing may be required for other uses.

## Permissions Overview

### ✅ Allows For

| Context | Permission | Notes |
|---------|------------|-------|
| Adobe applications | ✅ Full | Use within Adobe apps |
| Desktop (with Adobe CC) | ✅ Full | On licensed systems |
| Commercial (in Adobe) | ✅ Full | Work created in Adobe apps |

### ⚠️ Conditional

| Permission | Condition |
|------------|-----------|
| Document embedding | Some fonts allow, check properties |
| Web use | May require Adobe Fonts subscription |

### ❌ Disallows For

| Permission | Notes |
|------------|-------|
| Redistribution | Cannot distribute font files |
| Extraction | Cannot copy from Adobe apps |
| Modification | Not allowed |
| Server/CI | Requires separate licensing |

## Adobe Fonts Service

Adobe Creative Cloud subscribers can access thousands of fonts through Adobe Fonts:
- Desktop installation included
- Web embedding included
- No extra pageview limits
- Syncs across devices

## Embedding Rights

Adobe fonts may have embedding restrictions:
- Check font info in Adobe apps
- "Editable embedding" allows document embedding
- Some fonts are "print and preview" only
