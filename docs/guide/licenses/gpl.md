**SPDX Identifier:** `GPL-2.0` or `GPL-3.0` (with Font Exception)
**SPDX Page:** https://spdx.org/licenses/GPL-3.0.html

## Quick Summary

The GNU GPL is a strong copyleft license. For fonts, a "Font Exception" is often added to allow embedding in documents without requiring the document to be GPL-licensed.

## Permissions Overview

### ✅ Allows For

| Context | Permission | Notes |
|---------|------------|-------|
| Academic | ✅ Full | |
| Non-commercial | ✅ Full | |
| Commercial (Static) | ✅ Full | With Font Exception |
| Commercial (Server) | ✅ Full | |
| Web (Hosting) | ✅ Full | |
| Desktop | ✅ Full | |
| Redistribution | ✅ Full | Must use GPL |

### ⚠️ Conditional

| Permission | Condition |
|------------|-----------|
| Modification | Must release under GPL |
| Redistribution | Must provide source code |
| Document embedding | Only with Font Exception |

### ❌ Disallows For

| Permission | Notes |
|------------|-------|
| Proprietary derivatives | All derivatives must be GPL |
| Proprietary linking | Cannot link with proprietary code |

## The Font Exception

The "Font Exception" allows embedding the font in documents without requiring the document to be GPL-licensed:

```
As a special exception, if you create a document which uses this font,
and embed this font or unaltered portions of this font into the document,
this font does not by itself cause the resulting document to be covered
by the GNU General Public License.
```
