# Software Bundle License

[![License: Bundled Software](https://img.shields.io/badge/License-Bundled%20Software-8b5cf6)](#) [![Category: Bundled Software](https://img.shields.io/badge/Category-Bundled%20Software-8b5cf6)]

**SPDX Identifier:** Not on SPDX

## Quick Summary

Some fonts come bundled with specific software and are licensed only for use with that software. Terms vary - check the software's license agreement.

## Permissions Overview

### ⚠️ Varies by Bundle

| Context | Typical Permission |
|---------|-------------------|
| With bundled software | ✅ Usually allowed |
| Standalone use | ❌ Often restricted |
| Redistribution | ❌ Usually prohibited |
| Modification | ❌ Usually prohibited |

## Common Bundled Font Scenarios

### Office Suites
- Microsoft Office fonts
- LibreOffice bundled fonts
- CorelDRAW fonts

### Design Software
- Adobe Creative Suite
- Affinity products
- Sketch

### Operating Systems
- Windows system fonts
- macOS fonts (see [Apple-only](./apple-only))
- Linux distribution fonts

## How to Determine Rights

1. **Check the EULA** - Software license agreement
2. **Look for font embedding rights** - In font properties
3. **Contact the vendor** - For clarification
4. **Consider alternatives** - Open source fonts often available

## When in Doubt

If you're unsure about bundled font rights:
- Use open source alternatives (OFL, Apache, etc.)
- Purchase a separate font license
- Contact the software vendor for clarification
