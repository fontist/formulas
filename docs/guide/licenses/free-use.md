# Freely Usable

[![License: Free to Use](https://img.shields.io/badge/License-Free%20to%20Use-28a745)](#) [![Category: Open Source](https://img.shields.io/badge/Category-Open%20Source-28a745)]

**SPDX Identifier:** Not on SPDX

## Quick Summary

Some fonts are marked as "Freely Usable" or "Free to Use" without a specific open source license. These typically allow broad usage rights but may have some conditions. Always check the specific terms for each font.

## Permissions Overview

### ✅ Typically Allows

| Context | Permission | Notes |
|---------|------------|-------|
| Academic | ✅ Usually | Check specific terms |
| Non-commercial | ✅ Usually | |
| Commercial | ✅ Usually | Check specific terms |
| Desktop | ✅ Usually | |
| Web | ✅ Usually | Check embedding rules |
| Modification | ⚠️ Varies | May require permission |

### ⚠️ Conditional

"Free to Use" declarations vary widely. Common conditions include:
- No resale of font files
- Attribution may be required
- Modification may need permission
- Commercial use may have limits

## Usage Guidance

When a font is marked "Freely Usable":

1. **Check the source** - Visit the font's homepage for specific terms
2. **Look for license text** - In the font file or download package
3. **Contact the author** - If terms are unclear
4. **Document your usage** - Keep records of the license terms at time of use

## Difference from Open Source

"Freely Usable" fonts may not be open source because:
- Source files may not be available
- Modification rights may be limited
- Redistribution may be restricted
- No standardized license terms
