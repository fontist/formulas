# Creative Commons Attribution-ShareAlike 4.0

[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC%20BY--SA%204.0-28a745)](https://spdx.org/licenses/CC-BY-SA-4.0.html) [![Category: Open Source](https://img.shields.io/badge/Category-Open%20Source-28a745)]

**SPDX Identifier:** `CC-BY-SA-4.0`
**SPDX Page:** https://spdx.org/licenses/CC-BY-SA-4.0.html

## Quick Summary

The Creative Commons Attribution-ShareAlike license is a "copyleft" license. You must attribute the creator AND share any modifications under the same license.

## Permissions Overview

### ✅ Allows For

| Context | Permission | Notes |
|---------|------------|-------|
| Academic | ✅ Full | Must attribute, same license for derivatives |
| Non-commercial | ✅ Full | Must attribute, same license for derivatives |
| Commercial (Static) | ✅ Full | Must attribute, same license for derivatives |
| Commercial (Server) | ✅ Full | Must attribute, same license for derivatives |
| Web (Hosting) | ✅ Full | Must attribute, same license for derivatives |
| Web (Subsetting) | ✅ Full | Must attribute, same license for derivatives |
| Desktop | ✅ Full | Must attribute, same license for derivatives |
| Redistribution | ✅ Full | Must attribute, same license for derivatives |
| Modification | ✅ With conditions | Must use same license |
| Format Conversion | ✅ Full | Must attribute |

### ⚠️ Conditional

| Permission | Condition |
|------------|-----------|
| Any use | Must provide attribution |
| Modification | Must license derivatives under CC-BY-SA 4.0 |
| Redistribution | Must include license, same license for derivatives |

### ❌ Disallows For

| Permission | Notes |
|------------|-------|
| Proprietary derivatives | Cannot change license on modified versions |
| No attribution | Cannot use without giving credit |

## Key Difference from CC-BY

CC-BY-SA has a "share-alike" clause:
- If you modify a CC-BY-SA font, your modified version must also be CC-BY-SA
- You cannot make a modified version proprietary
- This ensures derivatives remain free and open
